E-Handicrafts Marketplace

A MERN stack based e-commerce platform for buying and selling handmade handicraft products online.
The platform supports Buyers, Sellers, and Admins with different functionalities and dashboards.

✨ Features

## 👤 Buyer Features

User Registration & Login
Browse handmade products
Search and filter products
Add to cart
Wishlist functionality
Place orders
View order history
Product reviews and ratings

## 🧑‍🎨 Seller Features

Seller dashboard
Add/Edit/Delete products
Upload product images
Manage product stock
View customer orders
Manage product listings

## 👑 Admin Features

Admin dashboard
Manage users
Manage sellers
Manage products
Manage orders
Remove inappropriate products/reviews

### ⭐ Product Review System

Buyers can rate products from 1–5 stars
Buyers can write reviews
Average product rating displayed
Total review count shown on product page

### ⚙️ Installation

Clone Repository
git clone <repository-link>
Install Dependencies
Frontend
cd frontend
npm install
Backend
cd backend
npm install

### ▶️ Run the Project

Start Backend Server
npm start
Start Frontend
npm run dev
